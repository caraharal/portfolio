PUBLIC PRD · P0 MVP

把参考图灵感，变成可执行的产品视觉工作流

这份公开版 PRD 聚焦用户问题、P0 取舍、验收标准与验证边界。阅读时间约 3 分钟。

查看 P0 范围 返回完整 Case Study
产品阶段
P0 MVP
需求来源
摄影生产工作流
核心用户
产品摄影师、美妆视觉创作者
核心判断
Original 决定产品是谁；Reference 决定如何拍摄

01 · PROBLEM

需求来自摄影生产，而不是“再做一个生图工具”

工作中很容易找到一张“感觉对”的参考图，却很难把这种感性判断翻译成摄影、灯光、置景、后期与模型都能执行的语言。

01

输入角色反复解释

每轮都要重新说明哪张图是产品，哪张图只提供风格。

02

产品身份容易丢失

瓶型、包装、Logo 和文字可能改变，参考产品甚至会抢占主体。

03

创作过程无法沉淀

图片、分析、Prompt、参数与结果散落在聊天和文件夹中。

当我有一张产品图和一张喜欢的参考图时，我希望系统帮我拆解参考图、保护原产品，并生成可复用的视觉方案，以便更快决定如何拍摄或继续生成。

02 · GOAL

先让核心生产闭环成立

产品目标
  • 把感性审美拆解为结构化视觉规则
  • 在风格迁移中优先保护产品身份
  • 减少重复解释参考图和产品限制
  • 让 Prompt、参数、输入和结果成为可复用资产
  • 在付费调用前识别输入错误与成本风险
当前不做
  • 不训练自有基础模型
  • 不承诺 Logo 与包装文字像素级还原
  • 不在没有登录、限流和预算控制时开放公共真实生图
  • 不在 P0 扩展团队协作、订阅、视频与批量 SKU
  • 不把单个成功案例描述为稳定成功率

03 · CORE FLOW

一条从灵感到资产的闭环

  1. 01双图输入

    Original 锁定产品；Reference 提供视觉语言。

  2. 02风格分析

    拆解色彩、灯光、构图、镜头、材质和情绪。

  3. 03生成控制

    确认主体、Logo、取景、画幅与创作备注。

  4. 04安全生成

    Reference 转成艺术指导，最终只编辑 Original。

  5. 05资产沉淀

    输入、Prompt、参数与结果回到 Experiment。

04 · P0 SCOPE

功能围绕工作流组织，而不是堆叠 AI 按钮

能力用户价值状态
双角色输入从入口明确产品与风格分工已实现
结构化风格分析把感性参考转成可执行艺术指导已实现
四平台 Prompt同一方向可跨 OpenAI、SD、Midjourney、ComfyUI 使用已实现
主体安全生成降低参考产品替换 Original 的风险已实现
画幅与主体控制让操作真实进入生成请求已实现
三阶段进度减少黑盒等待与重复点击已实现
Project / Library / Experiment保存输入、参数、Prompt、结果与备注已实现
Provider 分层无费用 Mock 演示；真实能力私有受控已实现

05 · KEY DECISIONS

四个决定产品边界的取舍

01

产品身份与艺术指导分工

Original 负责轮廓、比例、包装和品牌；Reference 只负责色彩、光线、构图、材质和氛围。

02

主体保真优先于参考相似度

结果再好看，只要产品被替换就是核心失败。主体安全模式先分析 Reference，最终只编辑 Original。

03

界面控制必须真实生效

主体、Logo、画幅、取景和备注必须进入请求，并随 Experiment 保存，避免虚假控制感。

04

公开展示与付费能力分离

公开页面只展示案例和 Mock 流程；真实 Provider 保持私有，避免密钥与费用风险。

06 · ACCEPTANCE

核心验收标准

验收关注产品承诺是否成立，而不只判断页面是否能运行。

输入与状态
  • 用户能清楚区分 Original 与 Reference
  • 输入不完整时不能发起真实生成
  • 更换 Reference 后旧分析与结果立即失效
  • 生成期间按钮锁定并展示三阶段状态
分析与生成
  • 分析返回完整结构化字段
  • 用户参数真实进入生成请求
  • 主体安全模式最终只编辑 Original
  • 输入、Provider、Prompt、参数和结果可追溯
公开边界
  • 公开页面不包含 API Key
  • 不提供会产生真实模型费用的按钮
  • Mock 测试不调用付费模型
  • 未经受控测试的数据不写成正式成功率

07 · VALIDATION

已有方向性证据，但不提前宣布胜利

ENCRE NOIRE 案例保留了黑色方瓶、木纹瓶盖和可辨识文字，同时迁移了植物标本式构图、纸张质感和低饱和自然色。
